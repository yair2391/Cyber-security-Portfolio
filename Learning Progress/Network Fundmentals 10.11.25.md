# TryHackMe Pre Security Course

# סיכום – יסודות הרשת (Networking Fundamentals)

##  מה למדתי
- על כתובות MAC Address ועל האפשרות לבצע Spoof לכתובת MAC
- פרוטוקול Arp 
- על ping ועל הפרוטוקול שבו הוא מתבצע icmp
- סוגי טופולוגיות רשת שונות כגון טופולוגיית כוכב, אוטובוס, וטבעת
- רכיבי רשת סוויץ וראוטר מה מטרתם
- Subnetting יתרונות ושימושים
- OSI Model מודל 7 השכבות לתעבורה של נתונים ברשת
- 3 ways hand shake, איך עובדים פרוטוקלים UDP TCP
- פרוטוקולים נפוצים והפורטים שלהם
- סוגי חומות אש ומטרתן
- שימוש בVPN היתרונות שלו, וסוגי הטכנולוגיות שבו הוא משתמש PPP, PPTP, IPSec
- סוגי DNS שונים
- פרוטוקול HTTP/S סוגי הבקשות get, post, put, delete
- סטטוסי קוד נפוצים כגון 200 אישור, 404 דף לא נמצא וכו
- חיפוש מידע דרך קוד המקור של האתר 
- Html injection 
- רקע כללי על CDN, WAF, Virtual Hosts, Web Servers

## יסודות לינוקס
- פקודות בסיסיות כמו ls, pwd, cd, find ועוד
- שימוש באופרטורים
- flags &  switches
- פקודות נוספות לעבודה עם מערכת הקבצים touch, mkdir, cp, mv ועוד
- הרשאות גישה במערכת לינוקס Read Write Execute
- ספריות נפוצות /var /etc /tmp /root
- סוגי Logs ומיקומם
- שימוש בעורכי טקסט שונים כמו Nano לדוגמה
- ניהול תהליכים (processes) וservices
- תחזוקת מערכת כגון logs, cron, package management

## יסודות Windows
- שולחן העבודה תפריטים שונים כגון start, search 
- שימוש במערכת הקבצים והתיקיות
- משתמשים פרופילים והרשאות
- Control panel & Windows setting
- Task manager
- ניהול המחשב compmgmt, System Tools, Storage,  Services and Applications
- היכרות עם  msinfo32 tool
- היכרות עם Resource Monitor (resomn)
- פקודות בסיסיות cmd, ipconfig, whoami, netstat
- היכרות עם regedit
- רקע כללי על windows update & security
- חומת אש ואבטחת רשת

##  תובנות אישיות
- יתרונות וחסרונות של רכיבי רשת וטופולוגיות רשת שונות
- מושגי יסוד  
- איך מתבצעת תעבורת נתונים דרך מודל השכבות ואילו חוקים חייבים להתקיים
- איך ניתן להגדיר חוקים מסוימים בחומת אש כדי למנוע מתעבורת נתונים מסוכנת להגיע ליעד 
- VPN יכול לשמש ככלי נהדר לאנונימיות ברשת וגלישה מאובטחת ללא אפשרות לדליפת מידע
- הבדלים בין סטטוסי קוד שונים ברשת והבנה מה כל אחד אומר
